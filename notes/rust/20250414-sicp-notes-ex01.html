番外

这一篇博客是 Rust 写 SICP 的番外，也就是具体课程内容之外的事情

那么这篇番外要说什么呢？

嗯哼，那就是介绍一下自己设计1的语言，KSL！

KSL 这个名字，L 很好理解，就是 Language，而 KS 则是我的名字的两个部分的首字母拼接而成，嘛，并没有太多其他含义

介绍

我们先来看一段 KSL 代码吧，下面的代码展示的是通过函数式和命令式两种方式来求 13! 的过程：

(* use function *)
Set[Factorial, Fun[{n},
  Block[
    Set[Factorial', Fun[{n, acc},
      If[Less[n, 0],
        -1,
        If[Eq[n, 0],
          acc,
          Factorial'[Sub[n, 1], Mul[acc, n]]]]]],
    Factorial'[n, 1]]]];
Print[Factorial[13]];

(*
  use vairable
*)

Set[n, 13];
Set[r, 1];
While[Greater[n, 1], {Set[r, Mul[r, n]], Set[n, Sub[n, 1]]}]; r

乍一看，这不就是 Wolfram2 嘛！，但是再一看就会发现： “嗯？怎么函数名可以使用单引号 '，定义匿名函数怎么是使用 Fun，为什么没有哪些常见的二元运算符？”

KSL 和 Wolfram 像的地方除了使用方括号调用函数以及使用花括号表示列表， 另外 KSL 的注释也是使用了 (* 和 *) 作为起始，以支持多行注释3， 其他地方就完全不是 Wolfram 了，更像是改了括号的 LISP

基本元素

KSL 目前有 11 种元素类型，分别是：

  • Unit：空元素，一般是函数返回值，要自己创建，需要使用 Unit[] 内建函数
  • Module：模块元素，包含了来自其他文件的环境信息，通过 Load 内建函数获得
  • Identity：符号或者是标识符，用于定义变量和绑定临时量，例如 x，Factorial'
  • Atom：原子，就是各种标签，或者是字面值，例如 #any_tags，#isn't
  • String: 字符串，就是字符串，可以索引，也可以有子字符串，例如 "hello?"
  • Number：数字类型，默认就是 f64，后续可能会接入 RMatrix 的数字体系
  • Matrix：矩阵，来自 RMatrix，是 Matrix<Double> 类型，有基本矩阵操作，通过 Matrix 内建函数构建
  • List：列表，这个就很常见了，可以通过 {} 构建，例如 {1, 2, 3, 4}，还可以使用 Range 内建函数构建
  • Lambda：匿名函数，这个是作为一个 Lambda 对象存储的，函数除了 Builtin 之外都是 Lambda，可以使用 Fun 内建函数构建
  • Builtin：内建函数，提供最基本功能，目前一共有 60 个
  • Apply：调用类型，即函数调用对象

其中最有特色的就是这个矩阵类型了，因为是自家的东西嘛！

其次就是字符串，因为我偷了一点懒，KSL 中的字符串是两个双引号中的 所有 字符，包括换行符号， 但是没法输入转义字符，不过也不太需要，换行可以使用手动换行，特殊字符除了双引号都会直接使用

基本语法

现在来看一下 KSL 该如何使用

首先就是变量，要定义变量，可以使用 Set 内建函数，当然，要更新变量的值也是这个函数，例如：

Set[n, 2];
Print[n]; (* => 2 *)
Set[n, 4];
Print[n]; (* => 4 *)

其中内建函数不能被覆盖，也就是重新定义，但是可以将内建函数绑定到其他符号上，例如：

Set[f, Print];
f[13]; (* => 13 *)

加减乘除都是使用内建函数，对应 Add，Sub，Mul 和 Div， 除此之外还有 Ln 和 Exp 来实现指数和对数运算， 也有最基本的三角函数 Sin，Cos 和 Tan

对于两个元素，最基本的操作是比较是否相同，如果相同，那么将返回 #t，即 True，不相同则是 #f，即 False， 特别的，对于数字类型，还可以比较大小，而对于 #t 和 #f，还可以使用基本逻辑运算内建函数 And，Or，Not 和 Xor

对于函数定义，可以将 Set 和 Fun 联合使用， 其中 Fun 第一个参数是一个形参列表，表示这个函数将会接受的参数，而后则是一个函数调用

在定义过程中，函数并不会被求值，这就意味着函数是可递归的，在上面的例子中也展现了这一点

要执行多条语句，除了可以使用 Block 内建函数来联合表达式，还可以使用列表

对于列表和 Block，都会按照顺序从前往后执行求值，区别就在于 Block 不会修改当前的环境，而列表不保证

Block[Set[x, 4], Add[x, 1]]; (* => 5 *)
Has[x]; (* => #f *)

{Set[x, 4], Add[x, 1]}; (* => 5 *)
Has[x]; (* => #t *)

在这里 Has 是一个用于判断某个符号是否已经绑定有值了， Block 不会泄漏 x，但是列表会

最基本的控制流有三个，If，Do 和 While，使用例子如下：

If[#t, 2, 1]; (* => 2 *)
Set[x, 0];
Do[Set[x, Add[x, n]], n, Range[0, 2, 10]];
Print[x]; (* => 30 *)
While[Greater[x, 10], {Print[x], Set[x, Sub[x, 5]]}];
(* =>
  30
  25
  20
  15
*)

注意，Do 和 While 都会返回求值部分最后的结果， 即 Do[Set[x, Add[x, n]], n, Range[0, 2, 10]] 会返回 ()， 而 While[Greater[x, 10], {Print[x], Set[x, Sub[x, 5]]}] 会返回 {(), ()}

一个脚本文件中执行多条指令可以使用分号分隔，这点在 Wolfram 也是如此， 但是 KSL 的分号需要且仅能用于分隔每一条表达式，而在 Wolfram 中分号还有更多其他用处

大概的语法就就是如此，非常简单，大部分功能都是通过内建函数来直接提供的，这算是作弊了，但是本来就是解释型语言，嘛
